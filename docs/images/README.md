# Screenshots to add

Use PNG files. Do not upload blurry mobile photos of the monitor.

Recommended files:

- `burst_read_waveform.png`
- `backpressure_waveform.png`
- `xsim_pass_log.png`
- `controller_architecture.png`

Before taking waveform screenshots, zoom so that these signals are visible:

- Request: `req_valid`, `req_ready`, `we`, `addr`, `wdata`
- SRAM: `sram_req`, `sram_we`, `sram_addr`, `sram_rvalid`, `sram_rdata`
- Response: `rvalid`, `rready`, `rdata`
- Burst/FIFO internals where permitted: counter, FIFO empty/full, write/read enables
